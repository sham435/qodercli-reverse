# QoderCLI Reverse

Independent Go-based AI coding assistant CLI.

An independently maintained community project, not an official Qoder product.

## Features

- Natural-language coding agent
- Multi-provider LLM support
- Tool orchestration
- MCP integration
- Skills and subagents
- GitHub integration
- CI/CD and releases
